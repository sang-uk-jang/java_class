# ☕ Java Programming

Java 프로그래밍 수업의 강의자료를 바탕으로 학습한 내용을 정리한 공간입니다.

강의 내용을 모두 기록하기보다는 **핵심 개념, 헷갈리기 쉬운 부분, 자주 잊어버리는 문법**을 중심으로 정리합니다.

## 📌 정리 목적

- **핵심 개념 정리**: Java 프로그래밍에서 반드시 이해해야 하는 개념 정리
- **헷갈리는 개념 비교**: 비슷하지만 차이가 있는 개념들을 비교하고 구분
- **자주 잊는 문법 기록**: 학습 중 반복해서 찾아보는 문법 및 사용 방법 정리
- **코드 예제 활용**: 개념을 실제 코드에 적용하며 동작 원리 이해
- **복습 자료 구축**: 시험 준비 및 추후 개발 과정에서 빠르게 참고할 수 있도록 정리
